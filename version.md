# Changelog & Versioning Policy

## 2026-07-18 - Starting serious versioning for the library.

### 1.0.0 - mstd as of now is c11 lib somewhat compatible with c89 using some extensions for VA, initializers, ULL etc.

---

### A Note on Versioning
This release marks the transition of `mstd` to formal semantic versioning (`MAJOR.MINOR.PATCH`). Development tracks API stability going forward, with public interfaces documented under strict backward-compatibility rules.
